# ✦ FunPay Plus

Расширение для Chrome, которое делает [funpay.com](https://funpay.com) удобнее и красивее: тёмная тема, живые обои с Live2D-аватаром и инструменты для продавцов.

> Неофициальное расширение, не связано с FunPay.

## Возможности

- **Тёмная тема** и выбор цветовой палитры сайта
- **Живые обои** с анимированным Live2D-персонажем, настраиваемая яркость
- **Автоподнятие лотов** по расписанию
- **Уведомления** о новых сообщениях и заказах, звук с регулировкой громкости
- **Быстрые ответы** в чате: заготовки сообщений в один клик
- **Перевод сообщений** в чате через Google Translate
- **Чат во встроенном окне** без перехода на другую страницу

Все настройки находятся во всплывающем окне расширения (иконка на панели браузера).

## Установка

### Из Chrome Web Store

Скоро.

### Вручную (из исходников)

1. Скачайте проект: зелёная кнопка **Code** → **Download ZIP**, затем распакуйте архив.
   Или через git:
   ```bash
   git clone https://github.com/HiruSanRu/FunPay_Plus.git
   ```
2. Откройте в Chrome страницу `chrome://extensions`.
3. Включите **Режим разработчика** (переключатель справа вверху).
4. Нажмите **Загрузить распакованное расширение** и выберите папку с файлом `manifest.json`.
5. Закрепите иконку FunPay Plus на панели (значок пазла → булавка) и откройте funpay.com.

Работает в Chrome, Edge, Яндекс Браузере, Opera и других браузерах на Chromium.

### Обновление

Скачайте новую версию, замените файлы в той же папке и нажмите ↻ на карточке расширения в `chrome://extensions`. Настройки сохранятся.

## Конфиденциальность

Расширение работает только на funpay.com, не имеет собственного сервера и ничего не отправляет разработчику. Настройки хранятся в браузере. Текст сообщений уходит в Google Translate только для перевода. Подробнее в [политике конфиденциальности](https://hirusanru.github.io/FunPay_Plus/docs/privacy.html).
